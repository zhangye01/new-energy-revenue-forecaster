# 全口径收入预测模型说明

## 项目电价粗算与基准测算

项目电价粗算独立配置年度现货均价、捕获率和假设来源。`P_capture = P_spot × captureRate / 100`。机制参照模式默认为项目捕获价，选择同类型机组模式时 `P_ref = P_capture + sameTypeSpread`。精算由逐时电量与价格计算捕获价后使用相同参照规则。

末年节点的年份取项目测算末年。末年价格可手动填写，留空时沿用末年前最近一个已填节点。相邻两节点之间按年度线性插值，即 `P(y) = P₁ + (P₂ − P₁) × (y − y₁) / (y₂ − y₁)`。节点年份采用节点原价。单年项目仅填写该年价格。新粗算快照保存实际采用的节点、插值方式和年度结果，历史快照沿用当时已保存的年度结果。

机制执行期由开始年月和执行周期（月）确定，开始月计为第一个月。系统按含首月的月份数自动计算结束年月，并按相同口径把历史起止年月反算为周期。两侧年度有效机制占比均为机制占比乘有效月份/12，机制补差为该占比乘（机制价−参照价）。策略损益按非机制电量计入。粗算策略采用首年损益、目标损益和年收敛步长，逐年向目标收敛。粗算的环境价值、费用及其他净收入、配储补充收益分别按项目全部结算电量填全周期固定度电值，净收入为正表示增加收益，为负表示扣减；配储项目使用储前结算电量。三项合计值直接加至度电结算价。基准测算的环境价值按非机制电量和各项兑现比例测算，费用、其他净收入及配储补充收益采用细化参数。粗算快照保存原始假设，交叉验证读取存档版本。

跨年汇总采用各年度电量加权。无完整年度电量时只提供年度价格与明确标注的年度算术平均，不提供全周期电量加权价。模型曲线当前仍含模拟逻辑，粗精差异只能用于参数与口径复核，不能作为真实预测准确率。

以下早期小时公式用于说明结构；机制补差与环境价值的实际年度口径以业务交接包及 `revenue-calculator.js` 为准。

## 产品边界

第一阶段聚焦风电、光伏发电侧项目。项目类型与配储解耦：

- 项目类型：风电、光伏。
- 配储条件：不配储、配建储能。
- 地域维度：全国省级区域。
- 时间维度：选择开始年份，最多预测 30 年。
- 计算粒度：每个预测年度均拆解为 8760 小时。

## 收入分项

| 分项 | 当前公式 | 后续可配置方向 |
| --- | --- | --- |
| 现货市场捕获电价 | 小时上网电量 * 小时现货价 * 捕获系数 | 接入省份真实 8760 现货预测曲线和项目节点捕获系数 |
| 差价机制结算收入 | 小时上网电量 * 差价结算比例 * (机制电价 - 小时捕获价) | 兼容煤电基准、竞价上限、政府授权差价、分年退坡 |
| 中长期合约交易损益 | 小时上网电量 * 合约比例 * (合约价 - 小时捕获价) | 支持年度/月度/分时合约、电量偏差、曲线分解和履约考核 |
| 环境价值兑现 | 市场化交易电量 × 各项价格 × 各项兑现比例后加总 | 绿证和绿电溢价的兑现比例合计不超过 100% |
| 三项费用 | 上网电量 ×（市场运营费 + 电网考核费 + 辅助服务费） | 以扣减金额列示，在全口径收入中减去 |
| 其他净收入 | 上网电量 × 其他净收入单价 | 单价为原其他收入减原其他费用，正数计收入，负数计费用 |

新版粗算 CSV 展示带符号的「费用及其他净收入」，单位为元/MWh。基准年度收入 CSV 对应列为 `primary_fees` 和 `other_net_income`，单位为元。历史结果按当版测算配置对账后拆出这两项。缺少原费用配置时，两项留空，原合计和度电净价可继续回查。备份数据及粗算快照以生成时的字段和值存档。

## 对齐顺序

1. 先对齐年度上网电量。
2. 再对齐现货捕获电价与现货收入。
3. 再对齐差价机制和中长期交易损益。
4. 再对齐环境价值、三项费用、其他净收入。
5. 最后对齐税费、贷款、现金流、IRR、NPV。

这样排查差异最快，因为收入侧和财务侧不会互相遮蔽。
