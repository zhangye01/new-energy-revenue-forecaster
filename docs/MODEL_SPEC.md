# 全口径收入预测模型说明

## 2026-10-19 粗算与精算共用口径

工作台新增独立年度关键参数粗算。`P_capture = P_spot × captureRate / 100`；现货均价按年份节点阶梯填充。机制参照模式默认为项目捕获价，选择同类型机组模式时 `P_ref = P_capture + sameTypeSpread`。精算由逐时电量与价格计算捕获价后使用相同参照规则。

两侧年度有效机制占比均为机制占比乘有效月份/12，机制补差为该占比乘（机制价−参照价）。策略与环境价值仅按非机制电量计入，费用按总电量扣除；配储及其他收入仍计入原有全口径。粗算快照保留原始假设，交叉验证不反向覆盖粗算、不激活预测版本。

跨年汇总采用各年度电量加权。无完整年度电量时只提供年度价格与明确标注的年度算术平均，不提供全周期电量加权价。模型曲线当前仍含模拟逻辑，粗精差异只能用于参数与口径复核，不能作为真实预测准确率。

以下早期小时公式用于说明结构；机制补差与环境价值的实际年度口径以业务交接包及 `revenue-calculator.js` 为准。

## 产品边界

第一阶段聚焦风电、光伏发电侧项目。项目类型与配储解耦：

- 项目类型：风电、光伏。
- 配储条件：不配储、配建储能。
- 地域维度：全国省级区域。
- 时间维度：选择开始年份，最多预测 30 年。
- 计算粒度：每个预测年度均拆解为 8760 小时。

## 收入分项

| 分项 | 当前公式 | 后续可配置方向 |
| --- | --- | --- |
| 现货市场捕获电价 | 小时上网电量 * 小时现货价 * 捕获系数 | 接入省份真实 8760 现货预测曲线和项目节点捕获系数 |
| 差价机制结算收入 | 小时上网电量 * 差价结算比例 * (机制电价 - 小时捕获价) | 兼容煤电基准、竞价上限、政府授权差价、分年退坡 |
| 中长期合约交易损益 | 小时上网电量 * 合约比例 * (合约价 - 小时捕获价) | 支持年度/月度/分时合约、电量偏差、曲线分解和履约考核 |
| 环境价值兑现 | 小时上网电量 * 环境价值单价 * 兑现比例 | 拆分绿证、绿电溢价、碳资产、补贴 |
| 综合费用 | 小时上网电量 * 综合费用单价 | 拆分市场运营费用、并网运行考核、辅助服务、偏差考核 |
| 其他收入项 | 小时上网电量 * 其他收入单价 | 支持容量补偿、需求响应、租赁、地方奖励 |

## 对齐顺序

1. 先对齐年度上网电量。
2. 再对齐现货捕获电价与现货收入。
3. 再对齐差价机制和中长期交易损益。
4. 再对齐环境价值、综合费用、其他收入。
5. 最后对齐税费、贷款、现金流、IRR、NPV。

这样排查差异最快，因为收入侧和财务侧不会互相遮蔽。
