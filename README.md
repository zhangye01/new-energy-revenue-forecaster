# 新能源全口径收入预测工作台

一个可直接在浏览器中运行的静态 Web 工具，用于新能源项目的电量配置、电价预测、全口径收入测算、基准结果总览和多方案对比分析。

## 在线使用

如果本仓库已开启 GitHub Pages，可通过发布后的 Pages 地址访问：

```text
https://zhangye01.github.io/new-energy-revenue-forecaster/
```

## 本地使用

下载本仓库后，直接用浏览器打开 `index.html` 即可。

也可以在项目目录启动一个本地静态服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

## 演示登录

工具内置的是前端演示登录，用于区分浏览器本地的不同演示用户，不是生产级账号体系。

```text
账号：demo1、demo2、demo3、demo4、demo5
密码：demo123
```

## 开发检查

修改核心计算或页面脚本后，建议先运行：

```bash
npm run check
```

该命令会执行 JavaScript 语法检查，并运行全口径收入测算黄金样例，覆盖机制结算、交易策略损益、环境价值兑现、综合费用、配储补充收益和缺失曲线提示。

同时它会运行架构守护检查，确保新增模块有测试、脚本加载不遗漏、`app.js` 不继续膨胀。GitHub Actions 也会在推送 `main` 或提交 PR 时执行同一套检查。

## 项目文档

业务口径、模型说明、工程化准入基线、风险台账、验收用例和烟测清单已整理到 [docs/](./docs/README.md)。继续开发前建议先阅读业务交接包、工程化准入基线和验收用例，避免页面迭代偏离既定口径。

## 主要功能

- 项目创建：配置省份、风/光类型、陆上/海上、装机容量、配储和测算周期。
- 结算电量配置：支持逐年总量模板、典型年8760曲线和省份典型曲线。
- 项目电价粗算：自动带入已填参数，补充关键假设并保留独立粗算快照。
- 历史电价分析：查看现货电价历史统计和分布。
- 电价预测工作台：生成 LSTM、XGBoost、Ensemble 三类模拟电价曲线。
- 收益参数补充与细化：带入已确认值，提示默认值和未填项核对，细化机制、策略、环境价值、费用及配储收益。
- 基准结果总览：形成基准场景简报、图表、年度明细和导出结果。
- 交叉验证：原粗算与已保存基准结果对照，提示明显偏差，保留粗算快照。
- 多方案对比分析：有效结果排名与真实参数扰动的首年敏感性分析。
- 本地备份：下载并恢复完整项目数据，同ID恢复为副本。

## 数据说明

首页市场概览、历史样本和三模型预测仍为演示数据，不能作为真实历史价格或独立回测证据。

工具默认在浏览器本地保存项目数据。直接访问网页不会上传本地测算数据，也不会共享个人浏览器中的项目结果。跨标签页冲突会暂停保存并提示；可先下载本页备份，再重新载入已保存版本。建议定期保存项目备份。
