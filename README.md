# 新能源全口径收入预测工作台

一个可直接在浏览器中运行的静态 Web 工具，用于新能源项目的电量配置、电价预测、全口径收入测算、基准结果简报和多方案对比分析。

## 测算周期供需输入

电价预测工作台支持六类供需要素。风电、光伏和水电各自可选择「电量与增速」或「装机与利用小时」。装机方式按当年有效装机乘以年等效利用小时计算发电量，装机按逐年增速滚动，利用小时默认沿用首年并可单年调整。省内负荷、联络线和非市场化出力按首年电量及逐年增速配置。联络线净额为正表示送出，为负表示受入，也可分别配置两个方向。

项目周期自动带入。两种构建方式分别保留参数，增速模板按当前方式校验，分月和典型日分时共用曲线模板。供需生成后统一预览并导出全周期小时数据。打开历史项目时，初始选择沿用其已保存的方式。

配置保存为独立版本。变更供需后需重新预测，原粗算快照和历史收益结果可继续查阅。已有案例可使用与供需版本匹配的合成价源。详细口径见[供需输入规范](docs/SUPPLY_DEMAND_INPUT_SPEC.md)，验证范围见[验收记录](docs/SUPPLY_DEMAND_QA.md)。

供需配置下方按「提交预测 → 任务状态 → 三模型结果 → 收益参数补充与细化」展示流程。供需就绪后可提交，运行中自动查询状态，也可手动刷新。任务失败可重试。预测结果在年度明细表上方展示各模型的均价趋势，点击图例可隐藏或恢复曲线。收益测算采用与当前输入匹配且通过校验的完整电价。接口和结果生效规则见[后台算法对接规格](docs/现货预测后台算法对接规格_V1.0.md)。

## 配储增量测算

在「收益参数补充与细化」核对配储往返效率并发起基准测算。基准测算沿用同一条现货价格和项目发电输入，对比有储与无储，按每小时功率、容量和效率计算站内发电的充放电日程。「基准结果简报」展示配储增量。「测算记录与明细」中的年度 CSV 记录放电收入、充电机会成本和同价增量，首年小时 CSV 含充放电量、荷电状态和储后上网量。

当前按日内价差配对，站内发电充电、日首日末空仓。配储增量以放电现货收入扣除充电的售电机会成本计算。容量补偿、辅助服务及其他独立收益按原配置计入一次，历史手工套利单价用于粗算。现有机制结算等其他收益仍基于储前电量口径。该模型暂未计入并网限额、跨日循环、退化和投资支出。

## 本地使用

下载本仓库后，直接用浏览器打开 `index.html` 即可。

也可以在项目目录启动一个本地静态服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

## 开发检查

修改核心计算或页面脚本后，建议先运行：

```bash
npm run check
```

该命令会执行 JavaScript 语法检查，并运行全口径收入测算黄金样例，覆盖机制结算、交易策略损益、环境价值兑现、综合费用、配储补充收益和缺失曲线提示。

同时它会运行架构守护检查，确保新增模块有测试、脚本加载不遗漏、`app.js` 不继续膨胀。GitHub Actions 也会在推送 `main` 或提交 PR 时执行同一套检查。

## 主要功能

- 项目创建：配置省份、风/光类型、陆上/海上、装机容量、配储和测算周期。
- 结算电量配置：支持逐年总量模板、典型年8760曲线和省份典型曲线。
- 项目电价粗算：自动带入已填参数，补充关键假设并保留独立粗算快照。
- 历史电价分析：查看现货电价历史统计和分布。
- 电价预测工作台：构建小时供需、提交预测并查看任务状态和 LSTM、XGBoost、Ensemble 三类结果。
- 收益参数补充与细化：带入已确认值，提示默认值和未填项核对，细化机制、策略、环境价值、费用及配储收益。
- 基准结果简报展示当前方案的结算电量、电价形成、首年现货分布、收入构成、配储运行和年度结果。网页与 Word 共用图表编号，按已保存的结果展示适用图表。历史测算与 CSV 在收益参数补充与细化的「测算记录与明细」中查看。
- 多方案对比分析：有效结果排名与真实参数扰动的首年敏感性分析。
- 本地备份：下载并恢复完整项目数据，同ID恢复为副本。

## 数据说明

首页市场概览、历史样本及既有模拟价格记录是演示数据，不能作为真实历史价格或独立回测证据。后台预测结果保留任务与模型来源。页面可展示年度均价，收益测算使用经校验并生效的完整价格。

工具默认在浏览器本地保存项目数据。主动提交预测时，当前项目的供需输入会发送至配置的预测服务。跨标签页冲突会暂停保存并提示。用户可先下载本页备份，再重新载入已保存版本。建议定期保存项目备份。
